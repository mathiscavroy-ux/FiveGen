# FiveGen · refonte — directions

Spec commune : page d'accueil de FiveGen (studio qui génère des scripts FiveM complets). Public : propriétaires et développeurs de serveurs RP FiveM, francophones, 16-35 ans, habitués aux outils de dev et à txAdmin. Message : « une phrase → une ressource complète, vérifiée, installée ». Ton : sérieux technique, pas gadget. Format : page web 1440 de large, responsive 375. Même contenu dans les trois versions (texte réel du site actuel). Pas de logos FiveM / Rockstar (site non affilié).

## Six candidats

1. **Meilleur designer · Collins (audacieux)** — produit en héros : le studio qui écrit en direct occupe le premier écran. Fond graphite, un seul vert « vérifié ». → **A · Console** (retenu)
2. **Meilleur designer · Experimental Jetset (rigueur)** — grille suisse, typographie énorme, une couleur signal. → fusionné avec 4
3. **Référence réelle · pages produit d'outils dev (Raycast, Linear)** — sombre, halo, bento. Écarté : c'est l'apparence « IA par défaut » que le site a déjà.
4. **Roulette (seconde 58 → n°19 Swiss Monochrome)** — blanc, noir, Geist, angles vifs. → **B · Suisse** (retenu)
5. **Univers du sujet · Los Santos de nuit** — ville procédurale au crépuscule, grand titre condensé, carte du serveur. → **C · Los Santos** (retenu, le plus audacieux)
6. **Univers du sujet · tablette MDT de police** — toute la page en interface de jeu. Écarté : la métaphore cache le message.

## Cartes des trois versions complètes

- **A · Console** — Emprunte : le produit visible en premier, grille 12 colonnes, mono pour tout ce qui est machine. Matériau principal : la génération animée (demande → questions → fichiers → vérification). Audace : un premier écran qui est le studio en marche. La forme vient du sujet : le client voit l'outil écrire, pas une promesse.
- **B · Suisse** — Emprunte : noir sur blanc, filets fins, chiffres comme matière, un seul rouge-orangé. Matériau principal : la typographie énorme et le vrai code Lua en bloc. Audace : le titre occupe toute la largeur. La forme vient du sujet : un script est un texte, la page se lit comme un texte bien composé.
- **C · Los Santos** — Emprunte : affiche de film, nuit et néon chaud, titre condensé. Matériau principal : une ville vectorielle au crépuscule avec les ressources posées dessus comme des lieux. Audace : la ville en plein écran. La forme vient du sujet : chaque script devient un lieu du serveur RP.
