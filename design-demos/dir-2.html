Code livré

Sécurisé côté serveur, par défaut.

Argent, items et récompenses sont validés sur le serveur : distances, jobs, cooldowns. Aucun événement exploitable par un tricheur.

1RegisterNetEvent('police_job:server:cuff', function(target)
2 local src = source
3 local xPlayer = ESX.GetPlayerFromId(src)
4 if not xPlayer or xPlayer.job.name ~= 'police' then return end
5 if Distance(src, target) > 3.0 then return end
6 TriggerClientEvent('police_job:client:cuffed', target)
7end)

ligne 4Le job est relu sur le serveur, jamais cru depuis le client.

ligne 5La distance entre les deux joueurs est contrôlée.
