À propos de FiveGen

FiveGen est un studio en ligne qui produit des ressources FiveM complètes (QBCore, Qbox, ESX Legacy, standalone) à partir d'une description : fxmanifest, configuration, scripts client et serveur, interfaces NUI, SQL et documentation d'installation.

Comment les ressources sont produites

Les ressources sont produites par un moteur de génération automatique de code développé pour FiveM, qui s'appuie sur une base de connaissances dédiée (frameworks, bibliothèques ox_*, natives, bonnes pratiques de sécurité et de performance). Chaque ressource passe ensuite par une vérification automatique (syntaxe Lua, manifest, références d'interface, événements client/serveur) et une correction automatique des erreurs détectées.

Comme tout code produit automatiquement, une ressource peut contenir des erreurs ou ne pas correspondre exactement à ta configuration de serveur : teste-la sur un serveur de développement et relis-la avant de la mettre en production.

Tes données

Nous conservons ton adresse e-mail, un mot de passe chiffré, tes crédits et les ressources que tu génères, uniquement pour fournir le service. Les descriptions que tu saisis sont transmises au moteur de génération pour produire tes ressources ; n'y inscris pas de données personnelles ou confidentielles. Tu peux demander la suppression de ton compte à tout moment via le support.

Si tu connectes un serveur avec le bridge, il envoie à FiveGen les noms de ses ressources démarrées, les versions de ses principaux frameworks et bibliothèques, les noms de ses jobs et grades, de ses items, de ses tables et de leurs colonnes, avec le type de ces colonnes. Cette liste ne contient jamais le contenu des tables ni de données de joueurs. Elle sert à écrire des scripts qui réutilisent ce qui existe sur ton serveur : les noms utiles sont transmis au moteur de génération avec tes demandes. Pour couper cet envoi, ajoute set fivegen_inventory "0" dans ton server.cfg. La liste déjà reçue reste enregistrée jusqu'à la suppression du serveur dans le studio ou de ton compte.

Le bridge envoie aussi le résultat de chaque déploiement et les lignes d'erreur de la console liées aux ressources déployées par FiveGen, pour les afficher dans le studio. Ces lignes reprennent le texte exact de l'erreur : si une ressource écrit le nom d'un joueur dans son message d'erreur, ce nom est envoyé avec. Quand tu demandes une correction à partir de ces erreurs, elles sont transmises au moteur de génération. FiveGen garde les 30 plus récentes par script, jusqu'à la suppression du serveur ou de ton compte.
